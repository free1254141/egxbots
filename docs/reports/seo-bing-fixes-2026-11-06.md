## 4. IndexNow (الـ 245 صفحة غير المفهرسة)

| العنصر | التفاصيل |
| --- | --- |
| المفتاح | `0b1fb5f854a1e5ffa567dc068238d844` |
| ملف التحقق | `web/public/<key>.txt` → يُخدم على `https://egxbots.com/<key>.txt` |
| المكتبة | `web/src/lib/indexnow.ts` |
| المسار | `POST /api/indexnow` (يتطلب نفس سر `REVALIDATE_SECRET`) |
| الربط التلقائي | `/api/revalidate` يرسل صفحات كل تاق بعد نجاح الإبطال |

### أمثلة تشغيل
```bash
# الصفحات الأساسية فقط
curl -X POST "https://egxbots.com/api/indexnow?secret=$SECRET"

# كل روابط الـ sitemap (دفعات 500)
curl -X POST "https://egxbots.com/api/indexnow?secret=$SECRET" \
  -H "Content-Type: application/json" -d '{"all": true}'
```

### نتيجة الإرسال الفعلي
- الـ sitemap يحتوي **362 رابطاً**، وتم إرسالها كلها إلى `api.indexnow.org` و`www.bing.com/indexnow` والرد **200 OK**.
- أول محاولة عبر المسار رجعت **403** (المفتاح كان لسه بيتوزّع على مواقع الحافة)، فأُضيف **retry واحد** عند 403 مع مهلة قصيرة.
