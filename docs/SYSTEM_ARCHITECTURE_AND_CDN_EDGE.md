## 2. ⚠️ تنبيه حاسم لجميع الوكلاء: حظر بروكسي كلاودفلير في مصر (Egyptian ISP DPI Block)

> [!CAUTION]
> **ممنوع منعاً باتاً تفعيل بروكسي كلاودفلير (السحابة البرتقالية 🟠) أو تحويل الـ Nameservers الخاصة بالدومين إلى كلاودفلير.**

### سبب المشكلة:
1. مزودو خدمة الإنترنت في جمهورية مصر العربية (وعلى رأسهم شركة **WE / Telecom Egypt** و**فودافون مصر**) يطبقون جدار حماية محلي بتقنية فحص الحزم العميقة (Deep Packet Inspection - DPI).
2. يقوم هذا الجدار بحظر وخنق نطاقات الآي بي المجانية الخاصة بكلاودفلير (`104.21.x.x` و `172.67.x.x`)، بالإضافة إلى إسقاط مسارات IPv6 غير المستقرة في أجهزة راوتر WE.
3. تفعيل البروكسي يتسبب في ظهور خطأ فوري للمستخدمين في مصر:
   `ERR_CONNECTION_TIMED_OUT` (This site can't be reached - egxbots.com took too long to respond).

### الحل المعتمد:
* النطاق يعمل مباشرة عبر خوادم **Vercel DNS**:
  * `ns1.vercel-dns.com`
  * `ns2.vercel-dns.com`
* الحماية وتوفير كوتا المعالج تتم عبر:
  * تقنية **Incremental Static Regeneration (ISR)** المدمجة في Next.js 15.
  * ترويسات `Cache-Control: public, max-age=14400, must-revalidate` لصفحات الأسهم العامة.
  * تخزين نتائج أدوات الشات بوت يومياً في ذاكرة الكاش `tool-result-cache.ts`.

## 3. أدوار الخدمات الحالية

| الخدمة | الدور | بيئة التشغيل |
|---|---|---|
| **Vercel** | النطاق، الاستضافة، الفرونت إند (Next.js 15)، والـ Edge Caching | السحابة الإنتاجية الأصلية |
| **Supabase** | قاعدة البيانات المركزية، جداول الأسهم، وإدارة المستخدمين | PostgreSQL السحابي مع RLS |
| **Hugging Face** | خادم بايثون (FastAPI)، بوتات التليجرام، ومهام الـ Daily Jobs | `weeasdwee/AI_BOT` (Docker) |
| **Resend** | إرسال إيميلات التفعيل، تقارير السوق، ونشرات المشتركين | سيرفرات Resend الموثقة بـ DKIM |
