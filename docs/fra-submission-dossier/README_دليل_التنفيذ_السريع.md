### الخطوة 3: النسخة الورقية (اختياري لكن موصى به بقوة)
* اطبع الخطاب والمرفقات وضع توقيعك.
* أرسلها عبر **البريد المصري بخطاب مسجل بعلم الوصول** موجهاً إلى:
  > **الهيئة العامة للرقابة المالية — الإدارة المركزية للتأسيس والترخيص (قطاع سوق رأس المال)**  
  > مبنى 136B، القرية الذكية، طريق مصر-إسكندرية الصحراوي، الجيزة.
* أو سلّمها في مكتب خدمة العملاء بالقرية الذكية وخذ إيصال الاستلام ورقم الوارد.

---

### الضمان الفني والبرمجي أثناء الانتظار:
* الكود والمنصة تعمل حالياً في النطاق الآمن 100% (أداة مسح فني + شات بوت بحثي عام + إشعارات إحصائية عامة).
* تجميد كامل لأي ميزات ربط مع شركات السمسرة أو التداول الآلي حتى ورود الرد الرسمي.
